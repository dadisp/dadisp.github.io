Privacy Policy

Last updated: 4 November 2026

Who this covers

Agm is a personal tool that its owner runs on their own computer, using their own accounts. There is no central Agm server that receives this data, and no public sign-up.

YouTube API Services

Agm uses YouTube API Services to upload videos to the owner's channels. Google's handling of data is described in the Google Privacy Policy, and use of YouTube is subject to the YouTube Terms of Service.

What Agm accesses and stores

  • Google and YouTube: the channel's ID and name, and an OAuth refresh token. Agm sends YouTube the videos, titles, descriptions and tags the owner schedules. Short-lived access tokens are requested when needed and are not stored. Agm does not read the channel's videos, comments or analytics.
  • Facebook and Instagram: the Page's ID and name, the Instagram account's ID and username, and access tokens. Photos for Instagram are first uploaded to the linked Page as unpublished photos so that Instagram can read them, and are deleted afterwards.
  • Telegram: the owner's chat ID, the bot token, and the messages the owner sends to the bot.
  • The owner's content: post text, schedules and media files.

Where it is kept

Everything above is kept on the owner's computer, in a local database, data folder and settings file. Account tokens in the database are encrypted with AES-256-GCM.

How it is used and shared

Agm uses this data only to schedule and publish the owner's posts, and to show their status. It shares data only in these cases:

  • The platform a post is for: when a post is due, its content goes to that platform.
  • The owner's Telegram: status notifications include the account's name and the start of the post's text.
  • An AI service, only if the owner turns on the assistant: the owner's messages to the assistant, plus account names and post details it needs to answer, are sent to the AI service the owner has configured. Tokens are never sent to it.

Agm does not sell data, does not show ads, and does not use analytics or tracking.

Cookies and browser storage

Agm's dashboard keeps a login token in the owner's browser. This website sets no cookies of its own. It is hosted on GitHub Pages, which may log technical data such as IP addresses.

Keeping and deleting data

Data stays on the owner's computer until the owner removes it. Removing an account in Agm deletes its stored token and its posts from the local database. This does not affect anything stored by YouTube or other platforms: videos already uploaded stay there and must be removed on that platform.

Revoking access

You can revoke Agm's access to your Google data at any time on the Google security settings page. Removing an account in Agm does not do this by itself. For Facebook and Instagram, remove the app under Business Integrations in your Facebook settings.

Contact

For privacy questions or complaints, open an issue on GitHub. Issues are public, so please do not include tokens or personal details.

Changes

The date at the top shows when this policy last changed.

Kebijakan Privasi

Terakhir diperbarui: 4 November 2026

Berlaku untuk siapa

Agm adalah alat pribadi yang dijalankan pemiliknya di komputernya sendiri, dengan akunnya sendiri. Tidak ada server pusat Agm yang menerima data ini, dan tidak ada pendaftaran umum.

YouTube API Services

Agm memakai YouTube API Services untuk mengunggah video ke channel pemilik. Cara Google menangani data dijelaskan di Kebijakan Privasi Google, dan pemakaian YouTube tunduk pada Persyaratan Layanan YouTube.

Data yang diakses dan disimpan

  • Google dan YouTube: ID dan nama channel, serta refresh token OAuth. Agm mengirim ke YouTube video, judul, deskripsi, dan tag yang dijadwalkan pemilik. Token akses berumur pendek diminta saat dibutuhkan dan tidak disimpan. Agm tidak membaca video, komentar, atau analitik channel.
  • Facebook dan Instagram: ID dan nama Page, ID dan nama pengguna Instagram, serta token akses. Foto untuk Instagram diunggah dulu ke Page yang tertaut sebagai foto yang tidak diterbitkan agar bisa dibaca Instagram, lalu dihapus.
  • Telegram: ID chat pemilik, token bot, dan pesan yang dikirim pemilik ke bot.
  • Konten pemilik: teks post, jadwal, dan file media.

Tempat penyimpanan

Semua data di atas disimpan di komputer pemilik, di database lokal, folder data, dan file pengaturan. Token akun di database dienkripsi dengan AES-256-GCM.

Cara data dipakai dan dibagikan

Agm memakai data ini hanya untuk menjadwalkan dan menerbitkan post pemilik, serta menunjukkan statusnya. Data hanya dibagikan dalam kondisi berikut:

  • Platform tujuan post: saat post jatuh tempo, isinya dikirim ke platform tersebut.
  • Telegram pemilik: notifikasi status memuat nama akun dan awal teks post.
  • Layanan AI, hanya kalau pemilik mengaktifkan asisten: pesan pemilik ke asisten, beserta nama akun dan rincian post yang dibutuhkan untuk menjawab, dikirim ke layanan AI yang dipilih pemilik. Token tidak pernah dikirim ke layanan itu.

Agm tidak menjual data, tidak menampilkan iklan, dan tidak memakai analitik atau pelacakan.

Cookie dan penyimpanan browser

Dashboard Agm menyimpan token login di browser pemilik. Situs ini tidak memasang cookie sendiri. Situs ini berada di GitHub Pages, yang bisa mencatat data teknis seperti alamat IP.

Penyimpanan dan penghapusan data

Data tetap ada di komputer pemilik sampai pemilik menghapusnya. Menghapus akun di Agm menghapus token dan post akun itu dari database lokal. Ini tidak memengaruhi data yang tersimpan di YouTube atau platform lain: video yang sudah diunggah tetap ada di sana dan harus dihapus di platform tersebut.

Mencabut akses

Anda bisa mencabut akses Agm ke data Google kapan saja di halaman setelan keamanan Google. Menghapus akun di Agm tidak otomatis mencabut akses ini. Untuk Facebook dan Instagram, hapus aplikasinya di bagian Integrasi Bisnis pada pengaturan Facebook.

Kontak

Untuk pertanyaan atau keluhan soal privasi, buat issue di GitHub. Issue bersifat publik, jadi jangan sertakan token atau data pribadi.

Perubahan

Tanggal di bagian atas menunjukkan kapan kebijakan ini terakhir berubah.

Agm is not affiliated with Google, YouTube, Meta or Telegram.
